# Screenshot Assets

## Current promotional screenshots

- `faryo-formula-mobile.png` — 390x844 mobile formula/code view.
- `faryo-formula-table-desktop.png` — 1440x900 desktop GFM/KaTeX view.
- `faryo-code-live-desktop-dark.png` — 1440x900 dark code/Live tmux view.

These images are generated from the anonymous browser fixture in
`apps/owner/local-tmux-owner/tests/browser-katex-smoke.mjs`. The fixture replaces
session metadata and conversation content before capture. It must never use a
real conversation, runtime Token, account, hostname, path, or domain.

Unreferenced screenshots and GIFs from the inherited UI were removed when this
set was introduced. Their history remains available through Git if an old
release needs to be audited.
