# Faryo 1.7.0

Faryo 1.7.0 is a source candidate that begins the Owner transcript migration to
a state-driven Preact boundary while retaining the proven Markdown/KaTeX
renderer and tmux-backed Codex workflow.

## Changes

- Adds a framework-neutral `ConversationStore` with session, generation and
  mode scopes so late polling or SSE responses cannot overwrite a newly
  selected session or Chat/Raw view.
- Moves loading, Codex startup, empty conversation, structured-history fallback
  and rich-render failure states into a focused Preact `TranscriptShell`.
  Existing Markdown/KaTeX, source-faithful copy, Live tmux and paged history
  remain isolated rendering adapters.
- Keeps very long conversations responsive by mounting rich Markdown/KaTeX
  bodies only near the viewport and releasing far-away descendants while
  preserving measured heights and complete question navigation.
- Makes the collapsed workstation identity pill safe for narrow screens,
  enlarged fonts and longer labels instead of clipping text against its right
  edge.
- Uses one measured VisualViewport snapshot for the mobile composer and
  conversation reserve. Browsers that already move fixed content are no longer
  compensated twice, and a tail-pinned conversation remains visible above the
  keyboard.

## Dependency decision

TanStack Virtual 3.17.8 was evaluated with an anonymous 600-row transcript
model. It substantially reduced mounted outer nodes and measurement work, but
the initial Preact/core adapter did not satisfy Faryo's 3 px history-prepend
anchor contract. The temporary dependency and adapter were removed. Faryo does
not ship a second React runtime or an unverified virtualization path; a future
trial must first pass immutable-list and prepend-anchor browser tests.

## Validation

- Canonical source gate: 199 Owner, 117 Gateway and 57 CLI Python tests plus
  Ruff, ESLint, formatting, dependency, TypeScript and browser-module checks.
- Preact transcript state tests cover obsolete response rejection, mode/session
  transitions and preservation of adapter-owned body DOM.
- Mobile layout fixtures cover the collapsed identity safe area and shared
  keyboard reserve.
- Anonymous 40-turn Markdown/KaTeX history keeps 5 rich bodies and 75 deferred
  bodies mounted, with 2,580 descendants, complete lazy paging, question
  navigation, Chat/Raw round trip and unchanged tmux geometry.

## Update

This source candidate is not yet the current public release. After its
deployment gate is complete, a tagged release can be installed with:

```bash
faryo update --version v1.7.0
```
