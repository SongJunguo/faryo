# Faryo 1.1.1

Faryo 1.1.1 consolidates the cloud route onto the Tencent Cloud owner,
removes the unused MCP remote tool surface, and improves Claude Code
session handling.

## Highlights

- The cloud route is renamed from `gcp` to `txy` with display label `TXY`,
  matching the Tencent Cloud owner that replaced the retired GCP gateway.
- The project definition anchor is renamed from `project.md` to
  `00-system/conops.md`.
- The MCP sidecar and its bounded workspace/task tool family are removed;
  the Gateway keeps the original handoff-package MCP tool only.
- Claude Code history discovery now skips subagent transcripts
  (`agent-*.jsonl` files and `isSidechain` rows), matching Codex history
  convergence rules.
- Claude Code sessions launched or resumed through Faryo now run with
  `--dangerously-skip-permissions`.
- Gateway owner backend hosts are configurable per route for tailnet
  owner endpoints.
