# Faryo 1.8.4

Faryo 1.8.4 restores the transparent conversation surface around the composer
without restoring the retired fixed-footer or VisualViewport geometry paths.

## Changes

- Keeps the composer in a bottom Grid track while extending the single
  conversation scrollport behind that track.
- Makes the footer fully transparent, leaving only the prompt shell itself
  translucent, so nearby conversation content remains visible while scrolling.
- Measures the complete footer with `ResizeObserver` and exposes its rounded
  border-box height as a CSS reserve. Textarea growth, attachments, status
  expansion and errors therefore cannot cover the final message.
- Preserves a tail-pinned reader after reserve changes without pulling a reader
  away from older history.
- Moves the latest-message control above the measured composer instead of a
  fixed pixel offset.
- Versions the new browser controller with the active immutable release and
  proxies it through the Gateway allowlist.
- Makes the canonical source gate reject drift among the Owner release, Python
  package and CLI runtime versions.

## Why this is not the old mobile implementation

The retired implementation attached the footer to the viewport with
`position: fixed`, translated it from VisualViewport measurements and guessed
keyboard geometry. This release uses no fixed positioning, viewport transform,
keyboard inset or device threshold. Chromium/Edge still owns keyboard resizing
through `interactive-widget=resizes-content`; the footer is anchored by the app
Grid and only its content height is observed.

## Validation gate

The controller unit test covers rounded measurement, coalesced resize events,
tail state and cleanup. The Chromium layout fixture verifies transparent
computed background, real overlap between the conversation and composer track,
dynamic textarea-height reserve, latest-message clearance, viewport contraction
and no document-level overflow. Final acceptance additionally requires an
ordinary reload on Android Edge, keyboard open/close, a visual transparency
check, healthy services and unchanged tmux pane identity and geometry.
