# Faryo 1.6.1

Faryo 1.6.1 fixes directory completeness in the Start/Resume working-directory
picker.

## Complete Folders list

- Owner no longer truncates a directory after 160 child folders.
- Every canonical child returned by Owner remains in the Folders section even
  when the same path is also a configured Root, Location, Parent, or Recent
  shortcut. Cross-section presentation never deletes a real filesystem child.
- The Hidden toggle remains available and remembered. Dot-directories are shown
  when it is enabled; the optional search filters only while the user has typed
  a query.
- Path canonicalization, directory-only validation, signed selection tokens and
  symlink/root containment remain enforced.

The reported missing folder was also a configured workspace root. Owner returned
it correctly, but Gateway's reserved-path dedup removed it from its parent's
Folders list. It now appears in both the appropriate Location and Folders
contexts.

## Automatic browser asset revision

Gateway page, auth, PWA, JavaScript, CSS and icon URLs now use a SHA-256-derived
content revision. Any mutable asset change receives a new URL automatically;
ordinary reload or a new tab is sufficient and hard refresh is never required.

## Upgrade

```bash
faryo update --version v1.6.1
```

This update preserves authentication, history, attachments and existing
tmux/Codex processes.

## Verification

- Canonical source gate: 177 Owner, 115 Gateway and 55 CLI Python tests, plus
  lint, format, TypeScript and reproducible browser bundles.
- Anonymous browser fixtures require a configured-root child to remain in
  Folders and verify 200 returned subdirectories without truncation.
