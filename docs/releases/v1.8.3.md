# Faryo 1.8.3

Faryo 1.8.3 completes the Android Edge composer placement work begun in v1.8.2.

## Changes

- Retains the verified native `interactive-widget=resizes-content` app shell and
  keeps VirtualKeyboard overlay disabled.
- On coarse-pointer devices, contracts both focused footer spacing and prompt
  bottom padding to 6 px plus any operating-system safe area.
- Keeps the normal unfocused composer spacing unchanged.
- Adds ordinary-reload support to the privacy-safe Android Edge CDP tool.

## Real-device decision

Three focused states were compared in the same Android Edge page:

1. the inherited 14/11 px footer/prompt spacing was visually higher than needed;
2. a true zero-gap state placed the DOM at the viewport edge but clipped the
   3 px focus outline, its 2 px offset and the rounded shell;
3. 6 px for both layers preserved every boundary and was the lowest complete
   rendering.

The remaining strips are browser and input-method UI, not web-page spacing. In a
normal Edge tab the address bar remains browser-owned even when the Fullscreen
API reports an active element. The maintained no-address-bar path is the
standalone PWA install entry on Gateway Home; an input-method toolbar is changed
only in that keyboard's settings.

## Validation gate

The browser fixture asserts coarse-pointer media matching, reduced focus
spacing, intact shell clearance and native viewport contraction. Final release
acceptance additionally requires a versioned ordinary reload on real Android
Edge, keyboard open/close, foreground and orientation checks, complete source
and browser suites, unchanged tmux geometry and healthy Owner/Gateway services.
