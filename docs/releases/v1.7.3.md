# Faryo 1.7.3

Faryo 1.7.3 completes the Android Chromium keyboard viewport handoff by keeping
browser-toolbar geometry out of the VisualViewport fallback.

## Changes

- Records the stable layout viewport height before the software keyboard opens.
- Selects an explicit `layout-resized` mode when the native viewport contract
  has already reduced that height; composer translation and duplicate history
  reserve are then both zero.
- Uses `visual-fallback` only when the layout viewport remains unchanged.
- Rebuilds the height baseline after a material width/orientation change and
  exposes only privacy-safe mode/shift diagnostics on the document root.

## Validation

- Unit fixtures cover native layout resize, visual-only fallback, partial
  overlap, stable layout and controller cleanup.
- Mobile browser smoke verifies the native viewport declaration and shared
  conversation reserve.
- The canonical source gate, live service health, ordinary reload and tmux
  geometry are checked before activation.

## Update

This source candidate is not yet the current public release. After its
deployment gate is complete, a tagged release can be installed with:

```bash
faryo update --version v1.7.3
```
