# Faryo 1.7.2

Faryo 1.7.2 is a source candidate that makes Android Chromium own the keyboard
layout viewport instead of relying on coordinate translation as the primary
composer path.

## Changes

- Declares `interactive-widget=resizes-content` in the Owner viewport contract.
  Supported Chromium browsers resize both layout and visual viewports when the
  software keyboard opens, so the fixed composer naturally remains at the
  usable page bottom. This follows the documented
  [Chrome Android viewport contract](https://developer.chrome.com/blog/viewport-resize-behavior).
- Retains the measured VisualViewport correction as a fallback for browsers
  that do not support the viewport contract.
- Keeps expanded composer geometry, transcript tail pinning, browser toolbar
  behavior and safe-area padding unchanged.

## Validation

- Browser layout smoke verifies the native keyboard viewport contract and
  shared conversation reserve.
- VisualViewport unit fixtures continue to cover full, partial and zero
  fallback compensation.
- The canonical source gate, live service health, ordinary reload and tmux
  geometry are checked before activation.

## Update

This source candidate is not yet the current public release. After its
deployment gate is complete, a tagged release can be installed with:

```bash
faryo update --version v1.7.2
```
