# Faryo 1.8.5

Faryo 1.8.5 is the corrected transparent-composer candidate. It supersedes the
rejected v1.8.4 preview.

## Changes

- Retains the v1.8.4 transparent footer, measured dynamic tail reserve and
  native keyboard viewport resizing.
- Declares one explicit App Shell Grid column and pins header, conversation and
  composer to it. The conversation and footer can overlap vertically without
  Grid auto-placement creating a second horizontal column.
- Extends the Chromium layout gate to assert that both overlapping surfaces
  share the App Shell's exact left and right edges in collapsed and expanded
  header states, with the keyboard closed and simulated open.
- Extends the privacy-safe Android Edge probe with composer mode, reserve,
  transparent background, padding and overlap geometry.

## Validation gate

The source gate must pass the controller tests, full-width Grid assertions,
dynamic growth, old-history anchoring, native viewport contraction and version
consistency. Release acceptance additionally requires an ordinary reload on
Android Edge showing v1.8.5, full-width main/footer geometry, transparent footer,
keyboard open/close, healthy services and unchanged tmux pane identity and size.

All gates passed on the local source deployment. Android Edge ordinary reload
reported a 384 px App Shell with 384 px conversation/footer widths, a fully
transparent footer and a measured 106 px overlap. Opening the keyboard reduced
the native viewport to about 346 px while retaining full width, transparency and
the 6 px focused clearance; closing, foreground restoration and an 810 px
landscape layout also passed. The complete source gate, paged long-history and
protected-resource matrices, 20-message delivery matrix, 22/22 runtime doctor,
error-level service log check and pre/post tmux identity/geometry comparison all
passed.
