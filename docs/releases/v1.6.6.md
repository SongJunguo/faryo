# Faryo 1.6.6

Faryo 1.6.6 makes live Codex and tmux output recover automatically when a
mobile browser, network path or intermediary leaves an SSE connection half
open.

## Self-healing live capture

- The browser now treats an event stream with no bytes beyond the bounded
  heartbeat window as stalled, switches to the existing polling fallback and
  reconnects with bounded backoff.
- A low-frequency capture remains active while SSE is healthy. Equal payloads
  are deduplicated before rendering, and a delayed safety response cannot
  replace a newer event frame.
- `pageshow`, focus, online and foreground transitions immediately refresh the
  visible session and recreate the live stream. Back/forward cache restoration
  no longer leaves a page whose stream was closed during `pagehide`.
- The primary SSE path remains responsive; safety polling is only a resilience
  layer and does not change Codex, tmux or terminal geometry.

## Upgrade

```bash
faryo update --version v1.6.6
```
