# Faryo 1.6.8

Faryo 1.6.8 keeps very long Markdown and KaTeX conversations responsive while
retaining complete paged history and full question navigation.

## Changes

- Mounts rich Markdown/KaTeX bodies only near the conversation viewport and
  releases far-away rich descendants while preserving measured block height.
- Keeps the newest streaming tail eager, and restores a requested question and
  answer before jumping to it.
- Caches question geometry instead of measuring every loaded question on every
  scroll frame.
- Preserves history-prepend anchors and uses immediate navigation for very long
  jumps, avoiding costly smooth scrolling across an entire transcript.
- Preserves custom Owner display labels when Gateway configuration is
  regenerated.

The rendering design follows the stable-key, measured-height, bounded-window,
and prepend-anchor contracts reviewed in DeepSeek Harness at pinned revision
[`b150a551b8d465e31e418e1b2eaf5e79bbb7d28e`](https://github.com/deepseek-ai/deepseek-harness/tree/b150a551b8d465e31e418e1b2eaf5e79bbb7d28e).
Faryo retains its independent implementation and branding.

## Validation

- Source, lint, dependency, Python 3.10/3.13, and browser module checks.
- Anonymous 40-turn long Markdown/KaTeX history with bounded rich DOM,
  cursor paging, complete question navigation, formula restoration, and a
  prepend-anchor tolerance of 3 px.
- Compact Chat/Raw round trip, mobile layout, copy and KaTeX regressions.
- Deployment health and unchanged existing tmux geometry.
