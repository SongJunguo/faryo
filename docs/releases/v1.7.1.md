# Faryo 1.7.1

Faryo 1.7.1 is a source candidate containing the Android Edge geometry fix for
the v1.7 transcript workbench.

## Changes

- Measures the mobile composer with any previous Faryo translation temporarily
  removed, so Chromium's own visual-viewport anchoring is not applied twice.
- Applies only the remaining overlap between the unshifted composer and the
  visible viewport bottom, including partial-overlap cases.
- Rechecks geometry asynchronously after the keyboard and browser toolbar
  animation settles, without delaying input or transcript rendering.
- Retains the shared conversation reserve, expanded composer dimensions and
  tail-pinning behavior introduced in v1.7.0.

## Validation

- VisualViewport unit fixtures cover full, partial and zero compensation and
  verify that stale translation is removed before measurement.
- Mobile layout smoke retains the shared keyboard reserve and narrow-header
  geometry.
- The canonical source gate, live service health, ordinary-reload asset version
  and tmux geometry are checked before activation.

## Update

This source candidate is not yet the current public release. After its
deployment gate is complete, a tagged release can be installed with:

```bash
faryo update --version v1.7.1
```
