# Faryo 1.6.5

Faryo 1.6.5 prevents a Codex CLI update prompt from consuming a newly launched
web conversation and adds bounded automatic Codex updates.

## Dynamic runtime discovery

- New installations no longer persist one NVM version's Codex path.
- Every managed new/resume launch and App Server restart follows NVM's recursive
  default alias, then stable user command locations and other valid NVM installs.
- A legacy generated `FARYO_CODEX_BIN` is only a final fallback. An operator can
  intentionally pin it with `FARYO_CODEX_BIN_PINNED=1`.
- Faryo resolves a matching Node/Codex pair to absolute paths for one exec only;
  the next launch performs discovery again.

## Automatic update before launch

- Auto-update is enabled by default and can be disabled with
  `FARYO_CODEX_AUTO_UPDATE=0`.
- A mode-600, file-locked preflight queries only the fixed official
  `@openai/codex` npm package when the discovered installation is npm-based.
- Current checks are cached for one hour. A newer version is installed with the
  matching NVM npm and verified before a fresh TUI process starts.
- Checks have a 15-second timeout and installs a 180-second timeout. Failure
  continues with the installed version and shows a bounded warning.
- The TUI update prompt is disabled only after this automatic attempt, so an
  updater can no longer exit before the requested conversation opens.
- A changed binary restarts the shared Codex App Server and refreshes the
  private slash-command catalog once.

The public fallback is also updated to the real Codex CLI 0.149.0 46-command
inventory: `/agents`, `/cd`, and `/pwd` replace removed 0.148-only entries.

## Upgrade

```bash
faryo update --version v1.6.5
```

## Verification

- Dynamic discovery tests cover recursive NVM aliases, version switches,
  legacy hints, explicit pins and missing pins.
- Update tests cover current, available, cached, failed and timeout paths,
  matching npm PATH, mode-600 state and failure-to-existing-Codex fallback.
- Isolated Codex 0.149.0 PTY inventory matches all 46 fallback commands without
  changing existing tmux geometry.
- The canonical source gate covers Python 3.10/3.13, formatting, lint,
  TypeScript, reproducible local bundles and existing Owner/Gateway/CLI
  reliability contracts.
