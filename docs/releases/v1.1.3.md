# Faryo 1.1.3

Faryo 1.1.3 moves the HP endpoint onto its own SSH reverse tunnel, drops
the GCP names the gateway still carried, and ships the gateway work that
landed after 1.1.2 was tagged.

## Endpoint routing

- HP reaches the Gateway through an SSH reverse tunnel instead of a
  tailnet address. The endpoint opens the tunnel outward and publishes
  its Owner on the Gateway host at `127.0.0.1:18766`, which is the HP
  route default. HP sits behind two layers of NAT, so the Gateway could
  not reliably open a connection toward it: once the direct path lapsed,
  probes still answered while TCP timed out. A tunnel the endpoint dials
  out has no such failure mode.
- `verify-reverse-tunnel.sh` no longer asserts `ownerLabel` or `session`.
  Owner `/health` answers with `ok` and `updatedAt` only, so neither
  value could ever match and configuring one made the check fail. It now
  verifies `ok`, which is what the endpoint actually reports.

## Gateway

- The sign-in and password pages can show a filing record in the footer,
  linked to the official filing site, driven by `FARYO_ICP_RECORD` in the
  same `faryo.env` as the other settings. Unset means no footer, so the
  field stays out of deployments that do not need it.
- The Cloud Run VM guard is retired. It hard-reset a Compute Engine
  instance after repeated health failures, which no longer applies once
  Gateway runs elsewhere, and its `/api/guard-health` endpoint had no
  remaining caller. `FARYO_GUARD_TOKEN` stays: a dispatched agent still
  uses it to call back into `/api/faryo/workorder/verify`.
- Route documentation and script defaults drop the retired GCP wording:
  `/gcp/` paths become `/txy/`, and two scripts stop defaulting to a
  tunnel unit that does not exist.

## Naming

- `apps/gateway/gcp-gateway` becomes `apps/gateway/server`,
  `run-gcp-gateway.sh` becomes `run-gateway.sh`, and
  `verify-gcp-reverse-tunnel.sh` becomes `verify-reverse-tunnel.sh`.
- `GCP_TUNNEL_*` becomes `GATEWAY_TUNNEL_*`. Endpoints that set these in
  a private env file need to rename the keys.

## Claude sessions

- The compact view strips the input composer box, and context usage
  treats an input count above the 200k window as evidence of a 1M window
  even when the model name carries no `[1m]` marker.
