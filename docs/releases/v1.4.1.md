# Faryo 1.4.1

Faryo 1.4.1 adds a privacy-safe Codex Goal status to the conversation page.

## Highlights

- The expanded Owner header now shows `Goal Active`, `Goal Done`, `Goal Paused`,
  `Goal Blocked`, or `Goal Limited` beside Git status.
- Session Details shows the same state and reported elapsed time. No goal keeps
  the header uncluttered and reads `No goal` in Details.
- On phones up to 420 px wide, an active Goal pill replaces the already
  truncated header Model label; the complete Model remains available in
  Details. Desktop keeps Context, Week, Model, Goal, and Git together.
- Goal state comes from structured `thread_goal_updated` events or a verified
  `create_goal`/`get_goal`/`update_goal` tool result. Faryo never infers it from
  terminal text.
- The parser discards objective, thread ID and tool payload before `/api/status`.
  Only status and bounded timing/usage metadata can reach the browser.

## Verification

- Canonical source gate: 130 Owner and 111 Gateway Python tests, all Node browser
  modules, Ruff, ESLint, Prettier and reproducible bundles.
- Incremental active-to-complete and explicit clear tests, plus direct structured
  goal event coverage.
- Anonymous 40-turn mobile history fixture with `Goal Active`, and a no-goal
  protected-resource fixture; neither exposes the fixture objective.
- Real 155 MiB long-session rollout resolves `Goal Done` in a bounded tail scan
  without returning objective text.
- Real Owner and Gateway-proxied views pass at 390x844 and 1440x900 with no
  horizontal overflow or tmux geometry change.

## Upgrade

```bash
git fetch origin --tags
git switch main
git pull --ff-only origin main
conda activate faryo
npm ci --ignore-scripts
scripts/check-source.sh
./apps/owner/scripts/start-web-owner.sh
```

Refresh existing session tabs once so `app.js?v=faryo-owner-workbench-32` and
the new local Goal module load.

## Rollback

Check out `v1.4.0` and restart Owner. Goal display is read-only and stores no
new private state, so rollback does not change Codex, tmux or conversation data.
This release is source-only and contains no custom binary assets.
