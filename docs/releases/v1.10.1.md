# Faryo 1.10.1

Faryo 1.10.1 is a focused context-window picker improvement.

## Change

- New and Resume now offer `Default`, `372K`, and `1M` context-window presets.
  `Default` still sends no override and follows the selected workstation's
  Codex configuration.
- The bounded Custom field remains available, so values such as `272K` can still
  be requested explicitly when needed.
- Current README and interaction documentation now describe the same presets as
  the browser UI. Historical release notes remain unchanged.

## Validation

- Gateway's 120 Python tests cover the exact preset markup and reject a
  reintroduced `272K` shortcut.
- The canonical source gate passes 229 Owner, 120 Gateway, and 65 unified-CLI
  tests, plus the maintained formatting, lint, TypeScript, bundle, and browser
  contract checks.
- The versioned local deployment preserves existing Codex App Server work and
  every pre-existing tmux session while an ordinary reload receives the updated
  launch picker.

Faryo remains source-only. Release assets contain the reviewed installer,
source archive, and SHA-256 manifests.
