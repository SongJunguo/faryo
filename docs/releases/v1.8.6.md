# Faryo 1.8.6

Faryo 1.8.6 is the long-conversation fast-scroll maintenance candidate. It
retains the v1.8.5 transparent composer and native mobile viewport contract.

## Changes

- Pauses Markdown/KaTeX hydration while the reader is scrolling rapidly and
  keeps height-preserving placeholders in the transcript.
- Resumes only the currently visible rich blocks after a 180 ms idle boundary,
  one block per animation frame.
- Records programmatic scroll-anchor writes so they are not mistaken for new
  reader input, and preserves an explicit absolute-top position while deferred
  content expands.
- Removes stale hidden entries from the hydration queue so revisiting a block
  always restores its rich content.
- Adds a privacy-safe real-session profiler that records only counts, timings,
  scroll geometry and sound/vibration call counts.

## Validation gate

The source gate must pass rich-block controller tests, Markdown/KaTeX and copy
regressions, full-history pagination, ordinary asset reload, service health and
tmux identity/geometry comparison. The privacy-safe A/B probe must show no
scroll-period regression and must not record transcript text, credentials,
domains or private paths.
