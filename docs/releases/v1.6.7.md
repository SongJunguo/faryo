# Faryo 1.6.7

Faryo 1.6.7 adds a safe per-session Codex context-window choice to new-session
and explicit-resume workflows.

## Session launch options

- The working-directory sheet now includes Default, 272K and 1M presets plus a
  custom whole-number field measured in K tokens.
- Default preserves the workstation's normal Codex configuration. A custom
  selection applies only to the newly started or resumed process and does not
  edit `~/.codex/config.toml`.
- Custom launches set both `model_context_window` and a 90% automatic
  compaction threshold. This makes larger windows effective without inheriting
  a smaller global threshold and keeps smaller windows from inheriting an unsafe
  larger threshold.
- History-card body clicks remain the fast zero-dialog resume path. The renamed
  `Options` action exposes folder and context choices when an explicit override
  is wanted.
- Gateway and Owner independently accept only bounded integers; no arbitrary
  CLI or TOML text crosses the browser boundary. The active model/provider must
  still support the requested window.

## Managed-session environment isolation

- Owner removes Faryo/Gateway service internals from a persistent tmux server
  at startup and immediately before managed launches. A stale installed-source
  `PYTHONPATH` is removed without discarding unrelated user Python paths.
- tmux clients, Codex CLI checks, automatic update and the shared Codex App
  Server all use the same sanitized child environment.
- User service units no longer export a source `PYTHONPATH`; the exact private
  venv already contains the installed Faryo package.
- Existing tmux/Codex processes are preserved during upgrade; the isolation
  applies to every newly created or resumed managed process.

## Upgrade

```bash
faryo update --version v1.6.7
```

## Verification

- Unit coverage checks validation, Gateway-to-Owner propagation, generated
  Codex arguments, auto-compaction and tmux launch metadata.
- Browser coverage types 272K, navigates to another folder, verifies the value
  remains selected, and checks the exact resume payload. It also verifies the
  1M preset and mobile layout containment.
- The canonical source gate covers Python 3.10/3.13, Owner/Gateway/CLI tests,
  formatting, lint, TypeScript and reproducible local browser bundles.
